Method and sources

Completed ticket with an authored PR means a ticket whose key appears in the title or description of a PR authored by that contributor and whose Jira status reached Done inside the sprint window. Delivery attribution uses GitHub's PR author.login field—not the person who merged the PR—because completed Jira tickets are handed to QA and reassigned after implementation. Each ticket counts once per contributor. Yan's yan-rnp and yee-snhu identities are combined; a genuinely multi-author ticket can appear under more than one contributor.

Current sprint forecast uses the primary MAS key in PR titles authored by Kevin between the sprint start and the refresh time. It includes both merged and open PRs, deduplicates tickets, and reads current Jira points/status. It is reported separately from completed velocity.

Completed Jira query, repeated per sprint:
project = MAS AND sprint = "SPRINT_NAME" AND resolutiondate >= "SPRINT_START" AND resolutiondate < "SPRINT_COMPLETE" ORDER BY key ASC
Current Jira scope: project = MAS AND sprint = "MAS - 2026.09.22", cross-referenced to Kevin-authored PR titles.
Fields: key, summary, status, issue type, resolution date, Story Points (customfield_10031).
GitHub repositories: MAS-SNHU/mas-platform, MAS-SNHU/mas-android, and RobotsAndPencils/hs-ios-repo.
Confluence HLD query: completed window through September 9 plus created >= "2026-09-09" AND created < "2026-09-23" AND (title ~ "HLD" OR label = "hld") for the active sprint. One active-sprint HLD qualified and was authored by Dominic Pepin; Kevin has zero active-sprint HLDs as of refresh.

Kevin's qualifying HLDs: MAS-1278 Learner Journey List, MAS-1277 Admin Settings, MAS-1279 Program Enrollment, and MAS-1480 Learning Coach Wrap Up.

Line counts are GitHub's full PR additions and deletions, so they include tests, configuration, documentation, generated files, and lockfiles—not only production source. This is a delivery-output comparison, not an individual performance score. It does not normalize for pairing, review work, operational work, leave, role differences, missing links, or the value of deleting code.
