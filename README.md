# Kevin delivery evidence

Private, source-backed dashboard summarizing Kevin Dickinson's delivery evidence across three completed MAS sprints and the current sprint in progress.

Open `mas-velocity-last-3-sprints.html` in a browser to view the dashboard. The methodology, source scope, and interpretation limits are included in the page.

This repository contains internal team delivery information and should remain private.

## Publishing

The private repository is the source of truth. This local checkout is configured so `git push origin main` sends the same commit to both repositories:

- Private source: `kdickinson-snhu/kevin-delivery-evidence`
- Public website source: `kdickinson-snhu/kevin-temporary-public`

The public repository is published with GitHub Pages at:

https://kdickinson-snhu.github.io/kevin-temporary-public/

The public site contains team names, delivery metrics, and ticket summaries. Treat every pushed dashboard change as publicly visible.
